Одностраничный сайт педагога с 30-летним стажем: 9 смысловых блоков, три темы оформления, форма заявки на Яндекс.Форме. Чистые HTML, CSS и JavaScript — **без сборщиков, без npm, без фреймворков**. Открывается двойным кликом по `index.html`.

> **Демо-проект. Все совпадения случайны.** Имя, стаж, цифры, дипломы и фото — вымышленные. Портрет сгенерирован ИИ, реальный человек не изображён. Перед публикацией нужно заменить заглушки ([чеклист](#что-заменить-перед-публикацией)).

## Быстрый старт

```bash
python -m http.server 5173    # или: npx serve .
```

Затем <http://localhost:5173>. Локальный сервер нужен для корректной работы iframe с Яндекс.Формами — по `file://` форма не отрисуется (показывается резервная карточка со ссылкой и телефоном).

## Достоинства

### Стек

**Ноль зависимостей.** Нет `package.json`, нет `node_modules`, нет сборки. Весь интерактив — [16 КБ ванильного JS](assets/js/main.js) без единой внешней библиотеки. Работает даже на статическом хостинге без Node.

### Доступность

- **Работает без JavaScript.** FAQ на нативном `<details>`, форма — iframe, навигация — обычные ссылки. Класс `.js` (включающий анимации) снимается страховочным таймером через 2,5 с, если скрипт не загрузился.
- **Контраст ≥ 4.5:1** (WCAG 2.1 AA) во всех трёх темах.
- Видимый фокус `:focus-visible`, skip-link первым в DOM, `aria-label` у иконочных кнопок, тач-цели ≥ 44×44 px.
- Поддержка `prefers-reduced-motion` — анимации отключаются, контент остаётся видимым.
- Не ломается при зуме 200 % и системном кегле 200 %: кегли в `rem`, а не в `px`.
- Замеры Lighthouse на `index.html`: доступность **100**, best practices **100**, SEO **100**.

### Производительность

- У изображений контента проставлены `width`/`height` — макет не «прыгает» при загрузке (CLS).
- `fetchpriority="high"` на портрете в первом экране, `loading="lazy"` на остальных, `preconnect` к шрифтам.
- При ошибке загрузки портрета показывается запасная рамка с монограммой — битой иконки не будет.
- Скрипт асинхронный (`defer`), шрифты с `display=swap`.

### Три темы одной строкой

| `data-theme` | Палитра | Шрифты |
|---|---|---|
| `1` Тихая гавань | тёплый беж, глубокий синий, терракота | Playfair Display + Inter |
| `2` Тихая точность | молочный, графит, приглушённый изумруд | PT Serif + PT Sans |
| `3` Сдержанная печать | светло-серый, бордо, золотисто-песочный | Lora + Manrope |

Меняется одна строка в начале HTML: `<html lang="ru" data-theme="2">`. Компоненты не знают, какая тема активна, — только CSS-переменные.

### Приватность и безопасность

Это не косметика, а раздельные решения, описанные в [DESIGN-SYSTEM.md](DESIGN-SYSTEM.md):

- **Оригиналы дипломов не попадают на сервер вообще.** Блюр или мозаика поверх скана — не защита: файл остаётся доступен по прямой ссылке. Публикуются только заранее очищенные копии.
- **`tools/sanitize.mjs`** снимает EXIF / IPTC / XMP и комментарии — в том числе GPS-координаты съёмки.
- В репозитории лежат **сгенерированные заглушки** `doc-01…06.svg`, настоящих данных в них нет.
- **Портрет синтетический** — сгенерирован ИИ, поэтому нет рисков с правами, согласием и портретной идентификацией.
- Данные формы уходят **напрямую в Яндекс.Формы**, минуя сервер сайта. Запрашивается только необходимое: имя, класс ребёнка, контакт.
- Служебные страницы (`ui-kit`, `concepts`, `privacy`) закрыты `noindex` — в поиске остаётся только лендинг.

### SEO

Один `<h1>`, иерархия заголовков без пропусков, `meta description`, Open Graph и Twitter Card, JSON-LD микроразметка `Person` (с `alumniOf` → `CollegeOrUniversity`, `knowsAbout`), `canonical`, SVG-favicon.

### Инструменты контроля

В `tools/` — шесть скриптов на Node (без зависимостей), которые ловят типовые ошибки вёрстки:

| Скрипт | Что проверяет |
|---|---|
| `check.mjs` | битые ссылки, отсутствующие иконки, неопределённые CSS-переменные, число `<h1>` |
| `fix-encoding.mjs` | порчу кириллицы от двойного перекодирования UTF-8 → CP1251 → UTF-8 |
| `sanitize.mjs` | снимает метаданные с JPEG / PNG / WebP, обезличивает имена |
| `make-concepts.mjs` | пересобирает страницы концептов из общей разметки hero |
| `make-diplomas.mjs` | генерирует безопасные заглушки документов |
| `fetch-photo.mjs` | докачивает изображение параллельными Range-запросами |

## Проверка перед коммитом

```bash
node tools/check.mjs                    # ссылки, иконки, CSS-переменные
node tools/fix-encoding.mjs --check .   # кодировка всех файлов
grep -rn "TODO" index.html privacy.html # остались ли заглушки
```

Все файлы — **UTF-8 без BOM**. Не редактируйте их через PowerShell 5.1 (`Get-Content` / `Set-Content` без `-Encoding UTF8`) и старые блокноты: кириллица превращается в «Р СѓСЃСЃРєРёР№».
